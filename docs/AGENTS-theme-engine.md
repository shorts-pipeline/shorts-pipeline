# Theme engine (`theme_engine/`)

Reduces repetitiveness by comparing the current journal to the **last 14 narrations** and, when similar, suggesting a **focus topic** so that episode goes in-depth on one theme instead of repeating the same surface coverage.

- **State**: `theme_engine/state.json` holds `entries` (last 14 after each successful `record`: `date_id`, `summary`, `journal_excerpt`, `closest_similarity`, and `closest_peer_date_id` = which other row in the window had max embedding similarity), `used_focus_topics`, and `focus_topic_queue`. `entries` can lag behind `narrations/` if `record` did not run or state was reverted. **`python theme_engine/theme_selector.py verify <date_id>`** recomputes and prints the closest peer (audit).
- **Flow**: Before narration, `generate-narration.py` calls `theme_selector.recommend(date_id)`. Similarity is judged against the **last 14 narration files on disk** (and `embeddings.json` when present), not only `state.entries`. When a focus topic is applied, the narration JSON may include **`theme_selector_decision`** (closest prior `date_id`, similarity score, threshold). After writing the narration JSON, `generate-narration` calls `theme_selector.record_narration(date_id)` to append that episode to state (trimmed to last 14).
- **CLI**: `python theme_engine/theme_selector.py 18030915 recommend` (get focus for a date); `python theme_engine/theme_selector.py 18030915 record` (add that date to state after narration exists). Disable in generate-narration with `--no-focus-topic` (legacy: `--no-theme-selector`).
- **Tuning**: `theme_engine/theme_selector.py` defines `MAX_ENTRIES = 14`, `EMBEDDING_SIMILARITY_THRESHOLD = 0.65` for **recommend** (embeddings only; no word-overlap fallback), and `SIMILARITY_THRESHOLD = 0.15` for **record** / backfill when embeddings are off. Embedding input length is controlled by **`THEME_JOURNAL_EMBED_MAX_ENTRY_CHARS`** (entry body slice), **`THEME_JOURNAL_EMBED_MAX_NOTES_CHARS`**, and **`THEME_JOURNAL_EMBED_MAX_TOTAL_CHARS`** — after changing them, run **`python theme_engine/theme_selector.py backfill`**, or **`refresh-embeddings <date_id>…`** for a partial re-embed. Legacy vectors may be noted in **`_embedding_store_note`** inside `embeddings.json`. See `theme_engine/README.md` for full design.

See also the root **`AGENTS.md`** index and **`docs/AGENTS-pipeline.md`** for the rest of the pipeline.
